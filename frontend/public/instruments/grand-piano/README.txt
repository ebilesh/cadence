Cadence adaptations: seven C1–C7 samples converted from MP3 to mono 22050 Hz
16-bit PCM WAV, capped at eight seconds. Intermediate pitches use resampling;
note lengths use an envelope. This compact single-velocity set does not model
pedal resonance or every MIDI instrument. No runtime third-party audio requests.
