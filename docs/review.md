# Review notes

I reviewed the existing project on October 4, 2026. I copied the full folder to `piano-coach-backup-20261004-123913` before changing files.

## What was unfinished

| Gap in the first version | What I changed |
| --- | --- |
| Timing could punish a delayed or slower recording | Fit start offset and tempo before measuring local errors, with an optional smooth drift fit |
| Wrong pitches could turn into missed and extra pairs | Keep separate one-to-one matches and error counts |
| Audio looked more certain than it was | Use pitch confidence weights, show estimates, warn about overlapping sounds, and hide scores for that warning |
| Bars used fixed time windows | Read the reference MIDI's tempo and time signature |
| The piano roll did not compare both sequences | Show reference outlines and aligned performance notes |
| Model suggestions were incomplete | Add rules, Ollama, and hosted API settings, validation, limits, and visible fallbacks |
| Some controls had no result | Add report JSON, help text, result navigation, clear results, and note inspection |
| Permission requests could wait forever | Add pending states, timeouts, and late-stream cleanup |
| Documentation described more than it verified | Rewrite it around the current code and record the remaining checks here |
| The demo depended on installing packages | Include a saved frontend build and a standard-library Python server |

The original input modes, analysis, report views, demo inputs, and optional model suggestions are implemented. Real piano accuracy still needs evaluation. I do not count synthesized samples as evidence of that accuracy.
